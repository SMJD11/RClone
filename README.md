# RClone

RClone is an app for browsing cloud storage, streaming media, and working with
encrypted vaults. It connects to existing cloud accounts through
[rclone](https://rclone.org/).

- **Mac:** Browse cloud files in the app or Finder, keep selected files offline,
  and unlock encrypted vaults with system authentication.
- **Android:** Play compatible audio and video and save encrypted downloads
  for offline use.
- **Transfers:** Follow upload and download progress. RClone checks uploads
  against provider checksums when available.

RClone is in development. Supported cloud providers and features vary by device.
This repository is a public overview of the app. No source code or installers
are published here.
